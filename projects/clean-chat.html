Clean Chat

Personal tool, open source (AGPL-3.0) · Sep – Oct 2026 · Project page · Repository

Clean Chat is a reading layer for AI chats. In a chat page you can erase what you already understand (collapsed, with undo), park what can wait, highlight and ask about what you don't understand, and save what matters into one local list that works across sites. A second part renders a Claude Code session as the same reading surface and answers side questions on the page without adding them to the session's context.

It is a Chrome extension plus a small local Python server, written in plain JavaScript and Python with no framework. I built it with Claude Code and reviewed the code; I use it daily and nobody else does yet. It is not on the Chrome Web Store.

The full description, with screenshots, the gesture list, the supported sites and how to install it, is on its own page:
